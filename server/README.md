# Сервер Morsegram

Ktor + PostgreSQL. Сервер хранит аккаунты, отправляет коды на почту, ищет людей по нику
и передаёт сообщения. Тексты сообщений он не видит: телефон отправляет уже зашифрованные байты.

## Что умеет

| Запрос | Что делает |
| --- | --- |
| `POST /auth/register` | почта + пароль, отправляет код на почту |
| `POST /auth/verify` | подтверждает почту кодом, выдаёт токен |
| `POST /auth/login` | вход по почте и паролю |
| `POST /auth/resend` | новый код (не чаще раза в минуту) |
| `GET /me`, `PUT /me/profile` | свой профиль: имя, ник, «о себе» |
| `GET /users/search?q=` | поиск людей по нику и имени |
| `GET/PUT/DELETE /contacts` | контакты |
| `POST /messages`, `GET /messages`, `POST /messages/ack` | доставка зашифрованных сообщений |

Защита: пароли хранятся как bcrypt-хеш, токены и коды — как SHA-256, на код 5 попыток и 10 минут,
на запросы входа и регистрации — не больше 10 в минуту с одного адреса.
